# 《紫微斗數全書》簡報來源

這是依使用者指定的 PDF 製作的二十頁「三卷重點導讀」，不是逐條收錄整本書，也不是個人命盤推算。

使用者資料夾內同名 PDF 的一份下載不完整；本次讀取完整的同書副本，共 337 頁。PDF 的文字層有缺字，因此依其目錄，對照以下同名原典核對摘要：

- [卷一](https://zh.wikisource.org/wiki/紫微斗數全書/卷一)：太微賦、紫微與天機等星曜問答。
- [卷二](https://zh.wikisource.org/wiki/紫微斗數全書/卷二)：安身命例、十二宮、安星與四化。
- [卷三](https://zh.wikisource.org/wiki/紫微斗數全書/卷三)：談星要論、生時核對及運限。

每頁 `notes` 保留卷別、章節與核對網址；原始 PDF 不公開。簡報描述的是古代術數體系，不把書中斷語當作經實證的個人預測。

內容主檔為 [ziwei-reading.json](ziwei-reading.json)。新增或修訂時先改此檔，再以相同資料更新 `engine/ziwei-deck.js` 的註冊物件，不得讓兩份資料不同步。

工作室：[開啟這份簡報](../index.html?topic=ziwei-reading)。內容與設計分開儲存，可修改文字、切換四套風格及三十種版面，再下載 JSON、可編輯 PowerPoint 或從放映頁列印 PDF。
